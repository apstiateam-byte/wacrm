# Supabase Auth email templates (Cluade)

Generated by `npm run emails:build` — re-run after changing NEXT_PUBLIC_APP_NAME /
NEXT_PUBLIC_SUPPORT_EMAIL / NEXT_PUBLIC_LEGAL_ENTITY.

Supabase Dashboard → Authentication → Emails → Templates. For each template, set the
subject and paste the whole HTML file into "Message body".

| Supabase template | Subject | File |
| --- | --- | --- |
| Confirm signup | Confirm your email for Cluade | `confirmation.html` |
| Reset password | Reset your Cluade password | `recovery.html` |
| Magic link | Your Cluade sign-in link | `magic_link.html` |
| Invite user | You've been invited to Cluade | `invite.html` |
| Change email address | Confirm your new email for Cluade | `email_change.html` |
| Reauthentication | Your Cluade verification code | `reauthentication.html` |
